# Formula Tracker

Formula Tracker is a comprehensive Formula 1 dashboard built with React, Vite, and Tailwind CSS. It features live race countdowns, standing views, historical data archives, schedules, news feeds, and an admin panel for site configuration.

## Features

- **Standings:** View current drivers' and constructors' standings.
- **Results:** Browse latest race outcomes and historical archives.
- **Schedule:** Keep track of upcoming Grand Prix weekends.
- **News:** Access the latest F1 headlines.
- **Profile:** Manage user accounts and authentication via Firebase.
- **Admin Configuration:** Adjust settings like maintenance mode, themes, live timing mode, and announcements directly from the UI.
- **Secure Authentication:** Complete email/password authentication, including password and email resets.

## Technologies Used

- **Frontend:** React, Tailwind CSS, Lucide Icons, Framer Motion
- **Backend/Database:** Firebase Authentication, Firestore
- **Build Tool:** Vite
- **Language:** TypeScript

## Setup & Configuration

This project requires a Firebase setup for the authentication and database features to work correctly. Ensure you configure your Firebase project and add your credentials before deploying or running locally.
